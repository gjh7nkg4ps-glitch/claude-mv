# BESLUTNINGER · indbakke fra hovedchatten

*Kun hovedchatten skriver i `docs/hovedchat/`. Code læser filen ved start og retter den ikke.*

**Regler**
- Her står kun **nye** beslutninger, som endnu ikke er skrevet ind i Codes papirer (CLAUDE.md, STATUS.md, planerne).
- Code skriver dem ind i sin egen plan. Når hovedchatten ser dem dér, sletter den dem her. Intet står to steder.
- **En beslutning er ikke en ordre.** Code bygger kun, når brugeren skriver "kør" eller peger på en besked i denne mappe.
- Beskeder til Code ligger her som `P8.x.txt`. Brugeren skriver fx "kør P8.32".
